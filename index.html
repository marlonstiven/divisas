Convertidor de Divisas

Rápido · Moderno · Hecho con JavaScript

Inicio

Acerca de

Autor: Marlon Stiven

Descripción: Aplicación web simple para convertir valores entre 20 divisas. Usa un objeto `rates` en JavaScript con tasas relativas.

Extras incluidos

  • Banderas con emoji junto a cada divisa
  • Validaciones (campo vacío / negativo)
  • Salida con 2 decimales (toFixed(2))
  • Interfaz responsive
